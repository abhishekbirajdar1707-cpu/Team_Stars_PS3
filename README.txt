# Team [Stars] - Metabolic Risk App

## How to Run This Application Locally
1. Ensure you have Python installed on your computer.
2. Open your terminal or command prompt.
3. Install the required libraries by running: 
   `pip install streamlit pandas plotly`
4. Ensure the dataset `diabetes_risk_prediction_dataset-selected-columns.csv` is in the exact same folder as `app.py`.
5. Run the application by typing:
   `streamlit run app.py`
6. The interactive web app will automatically open in your default web browser.
